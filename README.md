# Security Controls & Compliance Audit

## Project Overview
This project evaluates the security posture of a simulated organization, Botium Toys, through a structured review of existing security controls, risks, and compliance considerations.

The assessment identifies gaps in the organization's security environment and evaluates whether appropriate administrative, technical, and physical controls are in place to reduce organizational risk.

## Business Scenario
Botium Toys is a simulated organization undergoing a security assessment to identify weaknesses in its current control environment.

The project evaluates existing safeguards and identifies areas where additional security controls could strengthen the organization's overall security posture and support compliance objectives.
